## Key architecture

### Layout
- **Desktop**: Header (tabs) → Photo banner → 3-column (LeftPanel | SharkMap | RightPanel) → BottomStrip
- **Mobile**: Header → Photo banner → tabbed content (map/sharks/feed/research) → bottom nav
- `App.jsx` owns all state and orchestrates layouts

### BottomStrip (`src/components/layout/BottomStrip.jsx`)
- Desktop (`forceOpen=false`): receives `activeTab` + `onTabChange` from App/Header, 350px fixed height
- Mobile (`forceOpen=true`): internal tab state, fills parent via `flex-1 min-h-0`
- Tab id `'flashcards'` renders `SharkFlashcards` — labelled "Daily Quiz" in the UI
- Tab id `'bimini'` renders `BiminiRunTab` — embeds the Lemon Shark: Bimini Run game

### Daily Quiz (`src/components/research/SharkFlashcards.jsx`)
- 5 True/False questions generated by Claude, cached daily
- "More questions →" button on finish screen calls `getMoreSharkFlashcards(dateStr, round)` for 5 bonus questions; score accumulates across rounds; each round cached separately per session
- Score stored in `sessionStorage` (key: `shark_flashcard_score_YYYY-MM-DD`)
- Completed score stored in `localStorage` (`shark_quiz_last_score`) for popup reference
- **Important**: `const total = cards.length` must be declared BEFORE the useEffect that references it in deps — TDZ error otherwise

### Bimini Run (`src/components/media/BiminiRunTab.jsx`)
- Embeds the Phaser game from `http://192.168.71.250:5175` in an iframe
- Shows a controls hint bar: ⬆/W up, ⬇/S down, Space pause, tap top/bottom half on mobile
- Shows offline message if port 5175 is unreachable

### Quiz welcome popup (`src/App.jsx` — `QuizPopup` component)
- Shows once per day (gated by `shark_quiz_popup_date` in localStorage)
- Uses "Question 1" framing — intentionally avoids "quiz" language
- On accept: sets `researchTab='flashcards'` and (mobile) `mobileTab='research'`

### Claude (`src/utils/gemini.js`)
- Model: `claude-haiku-4-5`
- In-memory session cache for all calls
- Daily content (quiz, history) tries `/daily/{type}-{date}.json` static file first, falls back to live API
- Pre-generation script: `~/sharks-cron/generate-daily.js` on MacBook Pro (runs 2am via launchd)

## Rules
- No backend — client-side only
- Tab IDs are stable (`'flashcards'`, `'research'`, etc.) — labels can change but IDs are used in state/localStorage
- `daily/` folder on the server is never wiped by deploy (rsync excludes it)
- Don't change Claude JSON schemas without updating the pre-generation script too
